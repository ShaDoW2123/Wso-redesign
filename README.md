# We Study Overseas (WSO) — Official Home Page (v1)

India's premier international medical education and MBBS abroad advisory platform homepage. Engineered with a calm clinical blue aesthetic, high-trust healthcare credibility, and frictionless student counseling.

## Key Features & Polish
- **Atmospheric Celestial Hero**: Vertical sky-to-slate gradient with frosted floating capsule navigation.
- **Top Countries for MBBS Abroad**: Interactive 4-destination cards (Russia, Uzbekistan, Kazakhstan, Kyrgyzstan).
- **Interactive Twain-Style Key Benefits**: 3-card staggered scroll choreography with real MBBS metrics.
- **Accreditation Ticker**: Continuous marquee with official regulatory credentials (NMC, WHO, ECFMG, FAIMER, WDOMS).
- **Featured Medical Universities**: Clinical institution ledger with country filter tabs.
- **Advisory Terminal**: Free profile evaluation consultation form with confidential lead capture.
- **Uniform Architectural Eyebrows**: Standardized `• SECTION —` tracked header pills across all sections with single-color midnight navy (`#000B33`) typography.

## Quick Start (Run Locally)

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Push to GitHub

To push this repository to your GitHub account:

```bash
# 1. Initialize git
git init

# 2. Add all files
git add .

# 3. Commit
git commit -m "feat: complete WSO home page v1"

# 4. Set branch to main
git branch -M main

# 5. Link to your new GitHub repository
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

# 6. Push to GitHub
git push -u origin main
```

## Deploy to Vercel (Instant Showcase)

1. Go to [vercel.com/new](https://vercel.com/new).
2. Select your newly pushed GitHub repository.
3. Click **Deploy** (zero configuration required — default Next.js settings).
4. Share the live preview URL with your manager.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Icons**: Lucide React
- **Animations**: GSAP, Lenis (Smooth Scroll), Lottie
